# 投球砸墙 · Ball & Bricks

固定视角 3D 投掷砸墙小游戏。Three.js 渲染 + Rapier3D（Rust / WASM）刚体物理。主页提供 13 个场景：**砖墙**（9 列 × 40 行，底部竖砖托住每块底砖）、**高塔**（竖横交替 15 组）、**锥塔**（横竖交错、逐层对称收窄的阶梯锥塔）、**圆塔**（长轴沿圆周、次长轴竖直，逐层错缝垒高）、**圆环**（砖平放、短轴竖直，围圈错缝垒高）、**罐塔**（金属罐竖放堆成锥形）、**罐锥塔**（锥塔每个空格里立一个金属罐）、**高塔罐**（8 砖宽高塔，每个格子里一个金属罐）、**框墙**（12 砖宽，左右灰砖锁边，中间 10 列红砖，底部竖砖密排）、**罐金字塔**（地面上的 12 层罐子金字塔）、**砖堆**（长轴逐层在 X / Z 间交替的大长方体砖堆）、**砖柱**（双砖交错叠成的多根柱，间距拉大）和 **书桌**（地面小桌上一堆电脑、键鼠、水杯、盆栽和书架书）。砖块按真实比例（约 240:115:53）等比放大，背后有一整面大挡墙接住飞出去的球。


## 操作

- 在主页选择「砖墙」「高塔」「锥塔」「圆塔」「圆环」「罐塔」「罐锥塔」「高塔罐」「框墙」「罐金字塔」「砖堆」「砖柱」或「书桌」
- 移动鼠标（或触摸拖动）瞄准，砖块或地面上会出现珊瑚色圆环
- **按住蓄力，按住期间可以继续拖动调整落点，松开投掷**
- 蓄力越久球速越快，虚线是预测弹道
- `R` 或左上角「重置」按钮重置当前场景

镜头固定，不会随鼠标转动。
