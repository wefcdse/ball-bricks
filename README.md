# 投球砸墙 · Ball & Bricks

固定视角 3D 投掷砸墙小游戏。Three.js 渲染 + Rapier3D（Rust / WASM）刚体物理。主页提供 6 个场景：**砖墙**（9 列 × 40 行，底部竖砖托住每块底砖）、**高塔**（竖横交替 15 组）、**锥塔**（横竖交错、逐层对称收窄的阶梯锥塔）、**圆塔**（长轴沿圆周、次长轴竖直，逐层错缝垒高）、**圆环**（砖平放、短轴竖直，围圈错缝垒高）和 **罐塔**（金属罐竖放堆成锥形）。砖块按真实比例（约 240:115:53）等比放大，背后有一整面大挡墙接住飞出去的球。


## 操作

- 在主页选择「砖墙」「高塔」「锥塔」「圆塔」「圆环」或「罐塔」
- 移动鼠标（或触摸拖动）瞄准，砖块或地面上会出现珊瑚色圆环
- **按住蓄力，按住期间可以继续拖动调整落点，松开投掷**
- 蓄力越久球速越快，虚线是预测弹道
- `R` 或左上角「重置」按钮重置当前场景

镜头固定，不会随鼠标转动。
